What is DOM and what is its purpose?

The Document Object Model (DOM) is a programming interface for web documents. It represents the page so that programs can change the document structure, style, and content. The DOM represents the document as nodes and objects, allowing programming languages to interact with it.

How to select elements from the DOM?

There are several ways to select elements in the DOM:

1. getElementsByTagName() - Selects elements by tag name.

2. getElementById() - Selects a single element by unique ID.

3. getElementsByClassName() - Selects elements by class name.

4. querySelector() - Selects the first matching CSS selector.

5. querySelectorAll() - Selects all matching CSS selectors.

What is an event bubble?

Event bubbling is a concept in the DOM where an event starts from the target element and then propagates upward through its parent elements until it reaches the root.

The "bubbles" property indicates whether an event bubbles up or not.

Event bubbling can be stopped using stopPropagation().

What is a callback function and what does it do?

A callback function is a function passed as an argument to another function, which is executed after a specific event or condition occurs.

It allows customization of function behavior without modifying the original function.

Callbacks are commonly used in asynchronous programming and event handling.
